# RP 주임단 워크숍 현장 페이지

새 GitHub 저장소 `27jd-workshop`(https://richncohckim-bot.github.io/27jd-workshop/)에 이 폴더의 파일을 모두 올립니다.
사전 설문은 기존 `rp-survey` 저장소와 시트를 그대로 씁니다. 현장 페이지는 시트도 저장소도 따로 둡니다.
QR은 모두 `27jd-workshop` 주소로 만들어져 있으니 저장소 이름을 꼭 그대로 써 주세요.

| 파일 | 용도 | 누가 여나 |
| --- | --- | --- |
| screen.html | **진행 화면**: 덱 23장 + 실시간 QR · 업로드 현황 · 조별 사진 보드 · 다짐 보드 · 응답 수 (25장) | 진행자 노트북 → 프로젝터 |
| photo.html | ④-1 조별 결과물 사진 올리기 | 조장 (QR) |
| pledge.html | 한줄다짐 | 전원 (QR) |
| feedback.html | 만족도 조사 | 전원 (QR) |
| check.html | 연결 점검 (운영자용) | 전략HR팀 |
| config.js | ENDPOINT · 조 개수 · 조당 사진 수 | — |
| qr.js, qr-*.svg | QR 생성기와 미리 만든 QR | — |
| site.css, logo.svg | 공통 디자인 · 로고 | — |
| Code_현장.gs | 구글 시트에 붙여 넣을 저장 코드 | — |

## 1. 설치 (한 번만)
1. 새 구글 스프레드시트 생성 (예: "RP 주임단 워크숍 현장") — 사전 설문 시트와 별도
2. 확장 프로그램 → Apps Script → Code_현장.gs 붙여 넣고 저장
3. 함수 목록에서 `setup` 실행 → 권한 승인 (사진 · 한줄다짐 탭, 드라이브 폴더 생성)
4. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → URL 복사
5. config.js의 `ENDPOINT`에 붙여 넣기, `TEAMS`를 실제 조 수로 (Code_현장.gs 맨 위 TEAMS도 같게)
6. github.com → + → New repository → 이름 `27jd-workshop`, Public → Create
7. uploading an existing file → 이 폴더 파일 전체 끌어다 놓기 → Commit changes
8. Settings → Pages → Deploy from a branch / main / (root) → Save → 1~2분 뒤 https://richncohckim-bot.github.io/27jd-workshop/check.html 접속

## 2. 리허설 (가상 참가자)
- `screen.html?sim=1` 열기 → 오른쪽 위 배지 또는 **S** 키로 리허설 패널
- 사진 QR(14장) · 한줄다짐(21장) · 만족도(24장)에 들어가면 가상 참가자가 자동으로 올립니다
  - 속도: 실제 시간대로(사진 5분 · 다짐 5분 · 만족도 8분) / 빠르게(1분) / 바로
  - 수동 버튼: 사진 올리기 · 다짐 82개 · 만족도 응답 · 초기화
- 같은 브라우저 다른 탭에서 `photo.html?sim=1`, `pledge.html?sim=1`, `feedback.html?sim=1`을 열어 직접 제출하면 진행 화면에 바로 반영됩니다
- 리허설 기록은 그 브라우저에만 남고 실제 시트에는 저장되지 않습니다. 끝나면 패널의 **초기화**
- 탭끼리 연결하려면 GitHub에 올린 주소로 여세요 (내 PC에서 파일을 더블클릭해 열면 탭끼리 연결되지 않을 수 있습니다)

## 3. 실제 연결 점검
- `check.html` → **점검 시작**: 연결 → 현황 조회 → 다짐 · 사진 · 만족도 저장 → 조회 → TEST 기록 자동 삭제까지 8단계
- 같은 화면의 QR을 휴대폰으로 찍어 직접 제출해 보기 (직접 넣은 기록은 시트에서 지우기)

## 4. 진행 화면 조작
| 키 | 동작 |
| --- | --- |
| → PageDown Space | 다음 (조별 사진 보드에서는 다음 조, 다짐 보드에서는 다음 페이지) |
| ← PageUp | 이전 |
| 숫자 + Enter | 해당 장으로 이동 (예: 16 Enter) |
| G | 전체 목록 |
| N | 발표자 메모 · 계획 시각 |
| P | 발표자 창 열기 (노트북 화면에 메모 · 시계 · 다음 장, 프로젝터 창과 함께 넘어감) |
| F | 전체 화면 |
| B 또는 . | 화면 검게 |
| R | 데이터 새로고침 |
| A | 다짐 보드 자동 넘김 |
| Esc | 확대 · 목록 · 메모 닫기 |

- 조별 사진 보드: 사진을 누르면 크게, 늦게 올라온 사진도 자동으로 나타남
- 다짐 보드: 카드를 누르거나 Space로 한 장씩 크게, 카드 ×로 화면에서 숨기기 (시트 숨김 칸에 Y를 넣으면 완전히 내림)

| 12/29까지 | 덱의 18 · 19번(공통 문제 TOP3 · 해결 아이디어)을 빼고 모든 자료 확정 → 진행 화면 다시 생성 |

| D-1 | 교육장 PC · 프로젝터 · 와이파이(82명 동시 접속)로 check.html 다시 점검, QR 안내물 출력 |
| 1일차 저녁 | 조별 사진으로 18 · 19번 채우기 → 진행 화면 다시 생성 |
| 2일차 종료 후 | 시트 "만족도" 탭으로 결과 정리 |

덱(Slides)을 고치면 진행 화면(screen.html)을 다시 만들어야 반영됩니다. 수정 내용을 알려 주시면 다시 생성해 드립니다.
